= Интерфейс пациента: веб-форма записи

== Назначение
Форма позволяет пациенту увидеть свободные слоты и записаться на приём. Закрывает требования UR-01, UR-02, FR-02, FR-03.

== Поля формы
[cols="2,2,3",options="header"]
|===
| Поле | Обязательность | Источник / правило
| Врач | Да | Список специальностей из МИС
| Дата | Да | Календарь, не ранее текущей даты
| Время | Да | Только свободные слоты (FR-02)
| Номер направления | Для узкого специалиста | FR-03, BP-01
| ФИО пациента | Да | Идентификация записи
|===

== Результат записи
Карточка записи содержит: врача, дату, время, кабинет, номер талона, статус.

== Ошибки
* МИС недоступна — слоты не показываются, статус не меняется, факт в журнал.
* Слот занят — слот не показывается, предлагается другое время.
* Нет направления — запись недоступна, кнопка неактивна.
* Сервис уведомлений недоступен — ошибка в журнал, запись сохраняется.

== Связь с требованиями
UR-01, UR-02, FR-02, FR-03, BP-01, NFR-01, C-02.
