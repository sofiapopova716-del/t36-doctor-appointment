= Модель состояний записи

== Назначение
Модель описывает жизненный цикл записи пациента на приём: от создания до возврата слота. Используется для проверки FR-01, FR-04, BP-02, BP-03.

== Состояния
* «Записан» — запись создана, слот занят.
* «Подтверждён» — пациент подтвердил запись.
* «Отменён» — запись отменена пациентом или системой.
* «Не явился» — пациент не пришёл на приём.
* «Возврат слота» — слот освобождён после отмены или неявки.

== Допустимые переходы
|===
| Из | В | Условие
| Записан | Подтверждён | Пациент подтвердил запись (FR-01, переход выполняет только учёт записей по FR-04)
| Записан | Отменён | Пациент отменил запись (UR-02) или нет подтверждения (BP-02)
| Подтверждён | Не явился | Пациент не пришёл на приём
| Отменён | Возврат слота | Слот освобождён (BP-02, BP-03)
| Не явился | Возврат слота | Слот освобождён после неявки
|===
