== Назначение комплекта
Комплект описывает самозапись пациента на приём к врачу:
показ свободных слотов из МИС, создание записи, подтверждение,
отмену и отметку неявки. Терминал, мобильное приложение,
СМС-рассылка и отчётность перед страховой — вне границ.

== Состав
* `src/requirements.adoc` — требования BR, UR, FR, BP, NFR и ограничения C.
* `src/model.adoc` — модель состояний записи.
* `models/appointment-states.puml` — исходник диаграммы состояний.

== Порядок чтения
1. `src/requirements.adoc` — требования и ограничения.
2. `src/model.adoc` — состояния записи и переходы.

== Порядок сборки
[source,bash]
----
asciidoctor -D build src/index.adoc
----
Результат: `build/index.html`.
